## 상세 기록

### #4 퀴즈 정답이 한 칸씩 밀려 채점됨
- **현상**: 퀴즈 내용을 본인 정보로 바꾼 뒤 정답을 골라도 "아쉬워요!"가 나옴. 10번 문제는 어떤 보기를 골라도 정답이 아님.
- **원인 분석**: `app.js`는 `answer`를 0부터 시작하는 번호(0~3)로 비교함. 그런데 `content.js`에는 사람이 읽기 쉬운 1~4로 입력함 → 한 칸씩 밀리고, `answer: 4`는 존재하지 않는 5번째 보기를 가리킴.
- **해결**: 데이터는 1~4 그대로 두고(DynamoDB에도 1~4로 저장), 프론트엔드에서 불러올 때 `answer - 1`로 변환하도록 수정. 주석에도 "1~4" 기준이라고 적음.
- **검증**: 10문제 모두 의도한 정답을 골라 10/10 확인. → 커밋 `퀴즈 정답 번호를 1~4 기준으로 채점`
- **배운 점**: 데이터 형식(0부터인지 1부터인지)은 스키마나 주석에 분명히 적어 둬야 한다.
